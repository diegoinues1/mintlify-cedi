---
title: Card Management and Merchant Templates
---

The **"Cards"** module allows you to create, manage, and control corporate cards for the account, as well as define specific merchant spending rules using custom templates.

---

### Card Management Panel

From the main **Card Management** panel, users can view and manage issued cards. The following options are available in the top action bar:

- **Add Cedi card**: Initiates the flow for issuing or assigning a new card.
- **Merchant templates**: Accesses the template catalog for restricting or authorizing merchant categories.
- **Global report**: Allows exporting monthly transaction records for all company cards.

![title](/imagesu/cedi-tarjetas1.png)

---

### Downloading the Global Report

When selecting the **"Global report"** option, the system will display a modal window to generate the transaction report:

1. **Month Selection**: Select the closed monthly period you wish to consult from the drop-down menu (e.g., *August 2026*).
2. **Download**: Click **"Download CSV"** to get the file containing the consolidated transaction history.

![title](/imagesu/cedi-tarjetas7.png)

---

### Card Creation and Assignment

To issue a card, click the **"Add Cedi card"** button. The **"Create / assign cards"** form will be displayed, where you must configure the following fields:

- **Member**: Select the primary user to whom the card will be assigned.
- **Type**: Choose the card format (**Virtual** or **Physical**).
  - *Note*: If you select **Physical**, the mandatory **PAN (16 digits)** field will be enabled to capture the card number.
- **Alias**: Enter an internal identifier (e.g., *Office expenses*, *Travel*).
- **Limit**: Define the maximum amount assigned to the card.
- **Configure merchant blocking**:
  - **Use template**: Assigns a previously configured merchant rule.
  - **Custom**: Allows setting exclusive merchant rules for this card.

![title](/imagesu/cedi-tarjetas5.png)

#### Security Verification

Upon confirming card creation by selecting **"Create card"**, the system will request a **Security verification**. Enter the 6-digit code (generated by your authenticator app or sent via email) and click **"Verify"** to authorize the assignment.

![title](/imagesu/cedi-tarjetas6.png)

### Create New Merchant Template

To define a new set of merchant rules, select **"New template"**. On the configuration screen, complete the following sections:

1. **General Information**:
   - **Template name**: Identifying title (e.g., *Authorized fuel*).
   - **Description**: Optional internal context for the team.
2. **Template policy**:
   - **Allow**: The card will only accept purchases at selected merchants.
   - **Block**: Purchases at selected merchants will be declined, and all others permitted.
3. **Merchants**:
   - Use the search bar to locate specific business types or codes.
   - Toggle switches on or off for corresponding merchant categories (e.g., *Food and Restaurants*, *Automotive and Fuel*, *Construction and Home*, *Education*).
4. **Assign to cards**:
   - Search by alias or last digits to link the template directly to active cards.

To finish, click **"Create template"**.

### Merchant Templates

Accessing from the **"Merchant templates"** button, the user can view and manage the list of predefined commercial rules applied to cards.

![title](/imagesu/cedi-tarjetas4.png)

If templates exist, the table will display detailed information for each:

- **Template**: Name assigned to the template.
- **Description**: Internal use or context of the rule.
- **Merchants**: Policy applied (**ALLOW** or **BLOCK**) along with included categories (e.g., *Financial Services*, *Health and Wellness*, *Travel and Lodging*).
- **Scope**: Indicates whether it is a **Shared** (reusable) or custom rule.
- **Actions**: Options to edit or delete the template.
