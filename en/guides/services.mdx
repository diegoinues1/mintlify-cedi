title: Utility Services Payment
---

The **"Services"** module allows you to pay for multiple services contracted by your company or users, such as mobile telephony (airtime), water, electricity, gas, internet, and government procedures. 

For practical purposes and to illustrate the general operation of the platform, this manual will demonstrate the complete flow using the **airtime top-up (AT&T)** process. The behavior and step structure are equivalent for all other available services.

To initiate any payment, access the **"Services"** module from the system's side menu and select the **"Service payment"** option.

The system will display the main screen presenting the different available service categories (*Airtime*, *Water*, *Service payment*, *Government*), as well as direct shortcuts to the most common services and those frequently used by your user account.

![title](/imagesu/cedi-servicios1.png)
---

### Category and Provider Selection

At this stage, you must select the category of service you wish to pay for or top up.

For mobile telephony:

1. Select the **"Airtime"** option from the service catalog (or choose a direct service from the common options).
2. The system will display a pop-up window (*modal*) with the different available providers (Telcel, Movistar, AT-T, Virgin Mobile Packages, Bait, Internet para el Bienestar, Pillofon, among others).
3. Select the desired telephone company (for this example, **AT-T**).

Once the provider is selected, the system will direct you to the corresponding top-up flow.

![title](/imagesu/cedi-servicios2.png)
---

### Top-Up Amount Selection

In the first step of the top-up flow (**"Choose amount"**), the system presents the available package or balance options for the selected provider.

On this screen, you must:

- View the list of offered amounts (for example: Top-up $10, $20, $30, $50, $70, $100, $150, $200, $300).
- Select the box corresponding to the amount you wish to credit.

Once the amount is selected, the system will save your choice and automatically take you to the next step.

![title](/imagesu/cedi-servicios3.png)
---

### Phone Number Entry

In the **"Number"** step, the system will request the destination details for applying the top-up.

In this section, you must enter the following information:

- **Country code**: Select the corresponding code (by default `MX +52`).
- **Phone**: Enter the 10-digit mobile number to which the top-up will be applied.
- **Confirm number**: Re-enter the same phone number to validate that there are no input errors.

Once the entered numbers are verified, select the **"Continue"** option to proceed to the confirmation stage.

![title](/imagesu/cedi-servicios4.png)
---

### Transaction Confirmation

In the **"Confirmation"** step, the system presents a detailed summary of the operation before making the final charge.

On this screen, you must validate the following information:

- **Provider**: Company to which the top-up belongs (e.g., AT-T).
- **Top-up**: Amount of the selected package (e.g., Top-up $10).
- **Number to top up**: Beneficiary destination phone number.
- **Amount to pay**: Total to be debited from the account.
- **Source of funds**: Visual notification of the charge source (e.g., *"The charge will be made from the main account"*).

If you detect an error in the entered number, you can click **"Edit number"** to return to the previous step.

If all the information is correct, select the **"Confirm payment"** option to securely authorize the transaction.

![title](/imagesu/cedi-servicios5.png)
---

### Receipt and Payment Completion

Once the top-up is processed, the system displays the **"Payment successful!"** screen, confirming that the funds have been successfully credited.

This digital receipt details:

- Operation status (*Your payment was successfully applied*).
- Total amount paid and provider.
- **Authorization number**: Unique folio assigned to the transaction.
- **Reference / Phone**: Beneficiary mobile phone number.
- **Date**: Exact date on which the operation took place.

![title](/imagesu/cedi-servicios6.png)

In this window, you have the following additional options:

- **Download Receipt**: Allows you to download a digital PDF file with the operation summary.
- **Copy summary**: Copies key transaction information to the clipboard for quick sharing.
- **New payment**: Returns you to the main services screen to perform another operation.
