title: User Profile and Security
---

The user accesses the **"Profile"** screen from the system's side menu, where general account information, active security methods, contracted plan details, and company tax data are displayed.

---

### Profile Information

In the **Profile** section, the system displays the user's identifying details:

- **Email**: Email address associated with the account.
- **Full Name**: Primary user's name.
- **Team**: Name of the assigned team or group within the organization. From this option, the user can select **"Change / Manage"** to manage their team assignment.

---

### Security and Verification Settings

In the **Security Settings** section, the system allows managing enhanced authentication mechanisms to protect account access:

- **Authenticator app**: Management of TOTP codes using applications such as Google Authenticator or Microsoft Authenticator. The user can enable/disable this method by selecting **"Disable"** (if currently active) or **"Configure"**.
- **Email verification**: Option to confirm sensitive operations by receiving a code sent to the login email address. To enable it, the user must select the **"Configure"** option.

---

### Subscription Plan

In the **Plan** section, the system presents information regarding the current service level:

- **Plan Type**: Displays the contracted plan option (e.g., *Enterprise*).
- **Current period**: Validity of the active billing cycle.
- **Accounting AI agent usage**: Allows checking usage and metrics via the **"View details"** option.
- **Cancel subscription**: Action button to manage cancellation or modification of the current plan.

### Company Information

Scrolling down the screen displays the **Company Information** panel, detailing the registered legal entity data:

- **Identification**: Company name and RFC (Tax ID).
- **Address**: Street, Exterior No., Interior No., Neighborhood/Colonia, Municipality/Borough, State, and ZIP Code.
- **Contact**: Primary company phone number.
- **Additional Information**: Company category and registered Corporate Purpose.

## Configuration and activation of 2FA code (Authenticator App)

To activate the **Authenticator app** from the security module, the user must select the **"Configure"** option. The system will initiate the pairing flow requesting the use of a compatible application (such as Google Authenticator).

1. **App Installation**: On your mobile device (iOS or Android), access the App Store or Google Play Store, search for, and install the **Google Authenticator** app.
2. **QR Code Scanning**: Open the mobile app, select the option to add an account, and choose **"Scan a QR code"**.
3. **Screen Scanning**: Point the phone camera at the QR code displayed on the screen within the system.

5. **System confirmation**: Enter the active dynamic code shown on your phone into the text field on the platform and confirm the operation.
